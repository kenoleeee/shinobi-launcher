# Contributing

Thanks for helping! Bug reports, fixes and translations are all welcome.

- **Bugs:** use the [bug report form](https://github.com/kenoleeee/shinobi-launcher/issues/new/choose)
  and attach the debug log (**Help → Open Debug Log**). It never contains passwords.
- **Code:** see *Building from source* in the README. Keep changes focused, and test
  `npm start` and `npm run dist` on macOS before opening a pull request.
- **Scope:** the launcher only makes the official game run on macOS. Cheats, bots, auto-play
  and anything that changes gameplay won't be accepted.
